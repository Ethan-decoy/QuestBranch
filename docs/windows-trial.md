# Windows 安装与升级

适用版本：**0.3.0-dev.5 · Windows x64 预发布**。无需安装 Node.js 或 pnpm。实际附件及校验文件见 [Releases](https://github.com/Ethan-decoy/QuestBranch/releases)。

## 安装版

1. 下载 `QuestBranch-Setup-0.3.0-dev.5-x64.exe` 与 `SHA256SUMS.txt`，核对 SHA-256。
2. 运行安装程序，为当前 Windows 用户安装，可选择程序目录，不要求管理员权限。
3. 安装后通过开始菜单或程序目录中的 QuestBranch 启动，再在“模型与连接”连接自己的服务。

普通桌面配置默认位于 `%APPDATA%\questbranch`，研究默认位于其 `research` 子目录。“设置 → 本地存储”可将研究迁移到另一磁盘上的空文件夹；程序安装位置与研究保存位置分别选择。

卸载保留用户配置与研究资料，但不能替代备份。备份时保留用户配置目录与实际研究目录；外部智能体的账号和工作文件仍由后端管理。

## 免安装隔离试用

1. 下载完整的 `QuestBranch-0.3.0-dev.5-windows-x64.zip` 和 `SHA256SUMS.txt`，核对校验值。
2. 完整解压到可写目录，例如 `D:\Apps\QuestBranch`。保留 `win-unpacked/` 整个目录，不单独复制 EXE。
3. 双击顶层 `Start-QuestBranch.cmd`。首次可先新建或浏览研究；对话前在“模型与连接”连接自己的模型或智能体。

```powershell
Get-FileHash .\QuestBranch-0.3.0-dev.5-windows-x64.zip -Algorithm SHA256
Get-Content .\SHA256SUMS.txt
```

候选未签名，Windows 可能显示来源或 SmartScreen 提示。校验值只核对文件完整性，不替代代码签名。实际签名状态、附件校验值与验证范围以最终发行说明为准。

## 资料与账号

启动脚本将研究、Electron 配置和内置 Codex 配置分别保存在解压目录的 `data/research/`、`data/profile/`、`data/codex/`。重开同一脚本可继续研究；这些目录包含个人资料或凭据，不要随反馈分享。

直接运行 `win-unpacked/QuestBranch.exe` 使用普通桌面路径，可能打开日常资料。隔离试用请始终使用脚本；脚本设定了研究目录，设置中的目录迁移此时不可用。要换盘，正常退出后移动整个试用目录。自定义 ACP 后端仍遵循自身的账号和工作目录，脚本无法隔离所有外部后端。

连接自己的账号或 API 后才会发生真实模型调用。目录中的模型不保证套餐可用；不同后端的工具、原生会话和压缩能力以实际连接为准。固定响应验收不代表所有服务已实测。

## 升级与恢复

当前通过完整安装程序或 ZIP 手动升级，没有检查更新、后台下载或热更新模块。

**普通桌面或已安装版本：**正常退出 QB，备份用户配置和研究目录，再运行新版安装程序。程序文件会更新，研究和自选保存位置保留；打开后核对节点、报告和对话，必要时重新连接账号。

**旧 ZIP 隔离版迁移到安装版：**旧启动脚本使用独立的 `data/`，安装器不会自动查找或合并这些目录。在旧版导出研究空间 JSON，在新版通过“导入研究资料”导入；保留整份旧 `data/` 备份。JSON 不包含模型凭据和完整原生状态，需要时重新连接。

**ZIP 升级到 ZIP：**

1. 在旧版导出重要研究；正常退出 QB，确认没有正在进行的研究。
2. 备份整个 `data/`，将新版解压到另一个空目录，避免混用新旧应用文件。
3. 将旧版 `data/` 的副本放到新版目录，再通过新版启动脚本打开。不要同时运行两个实例写同一资料库。
4. 核对节点、报告、对话和界面设置；账号凭据无法恢复时重新连接。

从 0.3.0-dev.1 内部试用包升级时，沿用其顶层 `data/` 的布局。当前数据库和研究 JSON 均为格式 3，可导入格式 1、2。旧版是否能读取新版写入的资料不作保证；回退时使用旧应用与升级前的整份备份，不能只重装旧 EXE。

研究 JSON 导出不包含模型凭据、外部智能体工作文件或完整原生状态，不能替代整份备份。另一种安全试用方式是保持原版资料不动，将研究 JSON 导入新版的独立资料库。

## 范围与反馈

本版提供 Windows x64 安装程序和 ZIP。新装、自选路径、升级、研究位置保留、导入与重开和卸载保留资料由隔离 Windows runner 验证。升级验收使用已发布的 v0.3.0-dev.4 安装器和 ZIP，另验证旧 ZIP 的研究迁入安装版。

其他平台的安装与限制见[安装指南](desktop-installation.md)。本版 Windows 未签名，自动更新及真实厂商的全面兼容尚未验证。项目采用 MIT；固定 SessionWeave 快照及第三方组件的许可范围见 [LICENSING.md](../LICENSING.md)。

在 [Issues](https://github.com/Ethan-decoy/QuestBranch/issues) 附上版本、系统、连接类型与复现步骤；提供日志或截图前移除密钥和私人研究内容。
