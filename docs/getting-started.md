# QuestBranch 使用指南

## 开始一项研究

1. 新建研究空间，填写根问题、目标与约束。
2. 选中节点，在“对话”页讨论问题，或填写指令开始研究。
3. 点击“整理为报告”，将本节点对话与相关资料提炼为一份新报告；原消息和旧报告仍然保留。
4. 用“新方向”增加子问题，或接受报告提出的后续研究方向。
5. 用“分支比较”并排查看两份报告，再在新节点开展综合研究。

点击节点可阅读阶段摘要、完整 Markdown 报告、来源与研究记录。Ctrl+K 搜索问题与摘要；Ctrl+Enter 执行研究指令。画布支持缩放、定位、全图、折叠和自动布局，报告侧栏可以调宽。

## 模型连接

在“模型与设置”选择 Codex 账号、兼容 OpenAI 的模型服务或 Ollama，测试连接后保存。模型名称留空时，Codex 连接使用 Codex 自身的默认模型。程序未能自动找到 Codex 时，可填写本机原生可执行文件路径。

当前 Codex 连接使用提供的材料进行对话与报告整理，未开放网页检索、命令执行或文件修改。其他模型连接可选配置 Tavily 密钥，为研究提供公开网页资料；未配置检索时，报告明确说明没有进行外部检索。

兼容模型应能遵循 JSON 报告结构。“JSON 输出模式”按服务能力开启。无效输出会保存在研究记录中，已有报告继续保留。

模型密钥由本地进程持有，桌面优先使用 Electron safeStorage，浏览器预览使用本地密钥文件加密。模型凭据不会进入界面快照或研究导出；更换服务地址后，旧密钥不会自动发送到新地址。

`.env.example` 列出可选配置。应用读取启动进程的环境变量，不会自动加载 `.env`；通常直接使用本地设置页即可。

## 研究保存位置

浏览器预览默认保存于项目的 `.questbranch/research.sqlite`。Windows 桌面默认保存于 `%APPDATA%\questbranch\research\research.sqlite`。两者默认使用不同的数据目录。

在 Windows 桌面的“模型与设置 → 研究保存位置”选择一个空文件夹，核对路径后点击“迁移并重启”。全部研究空间、节点、对话、报告、历史、草稿与设置一起复制；数据库副本通过校验后才切换位置，原目录保留为备份。迁移前先结束或停止正在进行的对话与研究。

应用会记住所选位置。Electron 用户数据目录的 `storage-location.json` 记录路径。已选磁盘不可用时，程序显示错误；重新连接磁盘或恢复原路径后再启动。需要恢复旧副本时，关闭应用，把配置中的 `directory` 指向完整备份所在目录，再启动。

可以通过启动进程的 `QUESTBRANCH_DATA_DIR` 覆盖数据目录，优先级高于界面中保存的位置。浏览器预览也通过这个变量配置目录。避免同时启动两个实例操作同一数据目录。

## 导出与恢复

研究空间导出的 JSON 包含节点、对话、全部报告、来源、原始研究记录、问题修订与视图，不包含模型凭据。

通过左侧“导入研究资料”恢复，当前单文件上限 64 MB。已经存在的空间不会被覆盖；需要验证恢复时，请使用另一个数据目录。v0.2.1 的数据库版本为 2，支持旧版格式 1 的研究导出。数据库升级前保留备份。

## 当前平台范围

Windows 桌面与本地浏览器预览已经验证。macOS、Linux 的实际运行和安装包仍待验证。存储采用 Node 内置 `node:sqlite`，Node 24 可能显示该 API 的实验性提示。
