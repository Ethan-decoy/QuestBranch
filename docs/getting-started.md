# 开始第一次研究

简体中文 · [English](getting-started.en.md)

本指南适用于独立应用。安装、系统/CPU 与升级见[安装说明](desktop-installation.md)，常见条件见 [FAQ](faq.md)。使用 [DSH 集成](https://github.com/Ethan-decoy/QuestBranch-DSH)时，模型、工具与原生会话由宿主管理。

## 开始一项研究

1. 在侧栏“项目”旁点击加号，填写名称创建项目；保存位置可选，默认位置直接可用。选择文件夹时如果已有 QB 项目，点击“打开项目”即可重新打开。再点击项目行的加号，新建研究并填写根问题、可选标题与约束。一个项目可以放多项独立研究，初始示例保留在“已有研究”项目中。
2. 在“模型与连接”选择直接模型、Ollama 或 ACP 智能体；需要后端搜索与技能时选择具备相应能力的智能体。配置后再回到节点对话。
3. 选中节点，在底部输入框发送问题；查看报告或来源时，输入框仍用于当前节点对话。
4. 在对话中要求 AI 整理阶段成果或构建已确定方向；AI 通过工具保存本节点的新报告及所确定的子分支，原消息和旧报告仍然保留。
5. 保存报告后，用“新方向”选择来源报告版本并增加子问题，或接受报告提出的后续研究方向。仅有聊天的节点先整理报告；待研究方向不会自动运行。
6. 用“分支比较”并排查看两份报告，再在方向 A 的所属节点下开展综合研究；窗口会标明结果归属。

首次可用这条提问，再按自己的意图修改：

> 请围绕当前问题明确研究目标与约束，提出可独立深入的方向。将这份研究计划保存为阶段报告，并建立待研究方向；暂时不要继续研究子分支。

空对话的“填入示例提问”只写入空草稿，不自动发送或替换已有草稿。报告保存在节点内，属于阶段材料，不是任务目标。发送后查看真实工具活动与保存结果，再决定继续哪个方向。

点击节点可阅读阶段摘要、完整 Markdown 报告、来源与研究记录。Ctrl/Cmd+K 搜索问题与摘要；默认 Enter 发送、Shift+Enter 换行，中文输入法确认不会发送。在“设置 → 快捷键”可改用 Ctrl/Cmd+Enter 发送，选择即时保存在本机。画布支持缩放、定位、全图、折叠和自动布局，报告侧栏可以调宽。

详情栏底部的输入区固定显示，长文本在框内滚动。切换页签保留同一份节点对话草稿；点击输入框下方的模型或强度，可以直接选择当前连接提供的模型和思考档位，选择用于下一轮对话。Pi 读取模型目录，ACP 读取后端实际配置，未提供的选项不会补造；更换连接仍进入“模型与连接”。向上箭头发送，运行时同一位置显示停止图标，已收到的内容和成功的研究操作保留。

横向图与中心导图分别保存视角和手动位置，阶段摘要／简洁节点独立切换。中心图会记住分支左右分配；主动点击“恢复自动布局”可重新平衡。选中研究后，画布右上角的关联图标可查看相关研究，包含已折叠或当前聚焦范围外的目标；跳转后用返回按钮恢复原位置。

“分支比较”可选择两份报告的具体版本，填写每行一个共同维度，再开展综合研究。所选报告版本作为明确引用保留，综合指令要求在新报告中按共同维度形成表格；材料缺失仍须标为待核查。预算无法容纳所选材料时会报错，可提高预算或精简指令后重试。实际报告内容由所选模型生成。

子分支固定承接创建时的来源报告，父研究后来保存新版也不会自动替换它。详情标题下的来源入口可返回确切版本；比较选中的额外材料也按版本保存。旧分支没有记录来源时保留原状，继续研究时注明本次采用的背景，不补造历史来源。有旧报告的节点即使正在重试或本轮失败，仍可按旧版派生。

## 模型连接

“模型与连接”现在提供“模型”和“智能体”两种入口。模型适合直接调用模型；智能体通过 ACP 使用完整后端自身的工具与技能。

需要原生 Codex 时，选择“智能体 → Codex → 连接”，按提示完成 ChatGPT 登录，再选择后端返回的模型和思考配置，点击“使用此智能体”。原生 Codex 账号与原有模型入口的登录分别保存；QB 不复制其凭据。需要其他后端时可配置自定义 ACP 可执行程序与参数，实际兼容性取决于该适配器。

智能体的工具活动会显示在对话中；如需原生权限，直接在卡片上回应。停止或关闭应用会结束当前运行，已保存内容保留。`/skills` 等原生命令可直接输入，具体可用命令由后端声明。工具和插件不自动从其他客户端迁入。

可直接对模型或智能体说“构建刚才确定的这些子分支”，或“把当前讨论整理成报告”。AI 调用研究保存工具，将当前节点的完整阶段报告与已确定方向一起保存；只要求报告时不创建分支，无需寻找整理按钮。已有本节点报告时也可基于具体版本继续增加方向。保存后在“研究报告”页签阅读，子方向在图中等待你选择研究。

也可说“移除标题为 1 的分支”。QB 读取实际节点和确切报告版本后操作图谱，并展示真实调用。移除保留研究记录，可在活动旁点击“撤销”或请求恢复。工具本轮结束即失效，停止不会回滚已成功的保存和图谱操作。直接模型只使用 QB 的研究工具，原生搜索、技能等仍需智能体入口。

ACP 默认在当前项目文件夹工作，旧共享研究库仍使用 `agent-workspace`；连接中明确设置的工作目录优先。QB 保留对话和原生会话绑定，但外部客户端的隐藏历史、账号及工作文件仍由后端管理，不包含在研究 JSON 或数据库迁移中。原生工具完成或提供链接，均不等于研究主张已由 QB 核验。

以下说明对应“模型”入口。

通过侧栏齿轮或 `Ctrl / Cmd + ,` 打开设置。“外观”提供跟随系统、亮色、深色，选择即时生效并在本机保存。

“通用 → 界面语言”提供简体中文与 English，首次默认中文，切换即时生效并记住本机选择。语言只改变界面文案、状态和日期显示，不翻译研究节点、报告、来源或模型输出；切换时保留草稿和当前图谱位置。

在“模型与连接”选择账号登录、API 服务或 Ollama。提供商、模型与思考档位由 Pi AI 提供。账号选择提供商后点击“连接账号”，在浏览器授权，按 QB 中显示的设备码或手工步骤完成连接；选择模型和思考强度后保存。

账号连接默认使用 OM 工作记忆，无需另选会话策略或重新登录。API 服务默认核实原生压缩能力，也可在“更多设置 → 持续会话”手动选择 OM；能力未知和连接错误会明确提示。

误关授权网页后，点击“继续授权”重开，或点击“重新连接”重新开始。切回 QB 会检查授权结果；点击“取消连接”、关闭模型面板或按 Esc 可结束未完成的等待，已经连接的账号继续保留。

API 服务填写密钥，云平台等额外认证可使用“更多设置 → 配置认证参数”。自定义服务填写地址与兼容协议，模型可从目录选择或手填。旧 Codex 登录不会复制，需要在 QB 重新连接账号。模型目录不代表套餐开通范围，实际可用性以调用结果为准。

直接模型连接处理节点对话、QB 研究操作与报告数据，不执行命令或文件操作。可选配置 Tavily 密钥，为报告生成提供公开网页资料；普通对话不自动检索，未配置检索时报告明确说明资料范围。

模型应能遵循研究报告结构。“优先使用结构化报告输出”可提交报告工具参数；所有结果仍经过 QB 校验。无效输出会保存在研究记录中，已有报告继续保留。

模型密钥与账号凭据由本地进程持有，桌面优先使用 Electron safeStorage，浏览器预览使用本地密钥文件加密。模型凭据不会进入界面快照或研究导出；更换提供商、协议或服务地址后，旧密钥不会自动发送到新连接。账号授权、保存模型设置分别生效；关闭设置面板不会退出已连接的账号。

`.env.example` 列出可选配置。应用读取启动进程的环境变量，不会自动加载 `.env`；通常直接使用本地设置页即可。

桌面模型连接默认跟随系统代理，本地模型、OAuth 回调和研究 MCP 保持本机直连。浏览器预览的后端使用 `HTTP_PROXY`、`HTTPS_PROXY`、`NO_PROXY` 等环境变量，需要时在启动前设置。ACP 智能体沿用自身的网络配置。

连接失败的诊断日志保存在桌面用户数据目录的 `logs/network.log`（Windows 通常为 `%APPDATA%\questbranch\logs\network.log`）；浏览器预览保存在研究目录的 `logs/network.log`。日志自动轮转，只记录网络阶段、目标域名、状态、耗时及允许的错误码，不保存密钥、授权码或研究正文。

## 研究保存位置

桌面版采用“项目 → 研究”两层导航。一个项目文件夹中的 `.questbranch/research.sqlite` 保存该项目的全部研究、导航偏好和 QB 管理的会话状态；项目可以先为空。未自选位置时，默认放在原研究目录的 `projects/` 下。文件夹可以包含已有资料，QB 只创建自己的 `.questbranch/`；不要手动编辑数据库。通过侧栏加号后的文件夹选择重新打开或定位移动后的项目。

项目和研究均可右键或点击 `⋯` 重命名、固定。排序直接拖到另一项的上方或下方，松开后保存；研究限同一项目，固定项目与普通项目分别排序。键盘可用 Alt+↑/↓。项目名与研究标题的更改不修改文件夹名或根问题。切换研究恢复各自的节点、画布、报告阅读位置和草稿。归档保留内容，在所属项目菜单“已归档研究 → 研究名”中可只读打开、导出或恢复；阅读和导出不解除归档，恢复前不能修改研究或发送对话。关闭项目保留文件，可从加号入口选择原文件夹重新打开。

在“设置 → 本地存储”查看当前项目路径，用“迁移此项目”选择新文件夹并确认。迁移覆盖项目内全部研究、草稿、QB 管理的会话状态和已有历史恢复档案，校验后直接切换，无需重启，原位置保留为备份；文件夹内的其他资料和外部智能体文件不自动移动。研究菜单中的“移动到项目”只移动该项研究，保留其身份与连续状态。先结束涉及项目的对话与连接。

迁移目标不能选择该项目的恢复备份目录或其子目录。QB 会在目录选择及执行前校验真实路径，拒绝重叠位置并保留原项目。

旧版单研究文件夹在打开时升级为可容纳多研究的项目，原有 ID 和会话保留；首次 schema 升级前在数据库旁的 `backups/` 保留快照。旧共享库显示为“已有研究”项目，不按主题自动拆分；可迁移整个项目，或从研究菜单单独移动。数据库升级后不要用旧版程序直接写入。

应用配置目录中的 `application.sqlite` 保存项目路径索引、全局模型设置和加密的连接凭据；这些凭据不写入当前项目数据库。历史恢复档案位于 `.questbranch/backups/`，可能包含当时的加密设置与对应旧密钥；迁移时按原字节保留，应按完整本机备份保管，不会用它们替换当前全局账号配置。复制或移动完整项目文件夹，可保留研究和 QB 的会话状态；在另一台机器上需要重新连接模型。外部智能体自行管理的原生会话、账号和文件仍须按其规则备份，QB 不保证这些外部状态仅靠复制项目就能续接。项目路径不可用时会标示缺失，请重新打开正确文件夹，不会改用旧副本继续写入。

`storage-location.json` 和 `QUESTBRANCH_DATA_DIR` 继续决定旧共享研究库及默认项目父目录；环境变量优先。浏览器预览仍使用单个研究库，默认在工作目录的 `.questbranch/research.sqlite`，不提供系统文件夹选择器。避免多个实例或承载同时写入同一项目。

## 导出与恢复

研究空间导出的 JSON 包含节点、对话、全部报告、来源、原始研究记录、问题修订与视图，不包含模型凭据。

通过左侧“导入研究资料”恢复到当前项目，单文件上限 64 MB。已登记的同一研究或存在编号冲突的资料会被拒绝，不覆盖或重复恢复；在项目之间整理已有研究请使用“移动到项目”。验证独立恢复时使用隔离的应用配置与数据目录。当前 SQLite schema 为 4，研究 JSON 格式仍为 3，可导入旧版格式 1、2；升级前保留数据库备份，旧应用不能据此保证打开新版数据库。

## 当前平台范围

已发布 .5 成品覆盖 Windows x64、macOS 15 的 Apple Silicon/Intel 与 Ubuntu 24.04 x64；实际验证见 Release 的 VERIFICATION.json，其他系统及 ARM Linux 未覆盖。安装条件与签名见[安装说明](desktop-installation.md)。本地浏览器预览使用同一研究服务。存储采用 Node 内置 `node:sqlite`，Node 24 可能显示该 API 的实验性提示。

## 持续会话

API 入口按节点与连接保存持续会话；同节点多轮、生成报告和重开可继续。模型与连接的“更多设置”可明确选择 OM 工作记忆；原生优先需要该部署提供可核实的压缩与计数能力。未知能力或连接错误不会自动换策略。手填模型若没有容量资料，需要填入厂商公布的上下文容量；研究材料预算与会话窗口上限分别设置。

会话数据随 research.sqlite 一起迁移和备份。研究 JSON 恢复会保留源会话档案并建立独立会话；完整原生状态续传使用数据库备份，凭据另行配置。
