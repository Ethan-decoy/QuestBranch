# 常见问题

简体中文 · [English](faq.en.md)

## QB 与普通 AI 聊天、思维导图有什么区别？

一个节点是一项研究，保存自己的对话、报告、来源和历史版本。图谱显示各方向的关系与进展；选点继续、比较具体报告版本，原始研究脉络仍可回看。报告是节点内的阶段材料，不是要求完成的任务。

## 选独立版还是 DSH 集成？

[独立应用](https://github.com/Ethan-decoy/QuestBranch)提供自己的模型和 ACP 连接；[DSH 集成](https://github.com/Ethan-decoy/QuestBranch-DSH)在 DeepSeek Harness 内运行，模型、工具与原生会话由宿主管理。两者属于同一品牌的两种承载，安装方式、支持范围和资料位置分别看对应说明。不要让两种承载同时直接写同一研究库。

## 要注册 QB 账号或购买模型服务吗？

单用户版不要求 QB 账号。阅读和整理研究无需模型；AI 对话使用你自己连接的账号、API、本地模型或 ACP 后端。软件采用 MIT，厂商账号额度、服务费用和套餐可用范围由相应提供商决定。模型目录不保证你的账号能够调用每个模型。

## 如何检查和安装新版？

打开“设置 → 关于”或点击侧栏版本号，按当前安装方式检查、下载和更新。dev.6 或更早版本需先手动安装本版；平台差异、备份和恢复见[安装与升级](desktop-installation.md)。

## 它会自动联网搜索吗？

直接模型的普通对话不自动搜索。可配置 Tavily 为报告生成提供网页资料，或连接具备相应工具的 ACP 智能体；具体搜索和技能取决于后端配置。连接账号本身不代表已经具备联网研究能力，工具活动应以实际记录为准。

## 如何保存报告、建立子方向？

在当前节点对话中明确要求“保存阶段报告并建立刚才确定的待研究方向”。AI 通过研究工具保存报告和方向，旧对话及历史报告保留。只要求保存报告时不需要创建方向，新方向也不会自动研究。空对话中的示例提问只填入草稿，由你编辑并发送。

## 为什么“新方向”不可用？

手动派生需要当前父节点自己的来源报告。先在对话中保存该节点的报告，或请求 AI 同时保存研究计划与方向。祖先报告可以作为背景，不能冒充当前父节点的报告。至少两个节点分别有报告后，才可以比较它们。

## 如何开始自己的研究？

示例用于了解图谱、报告和来源。可从“创建自己的研究”或研究空间旁的加号开始，示例会保留；也可以继续讨论示例中的问题。示例中的项目材料不应被当成你的真实研究结果。

## 本地优先是否代表所有内容都不离开电脑？

研究数据库保存在本机。选择云端模型或外部工具时，相关材料会发送到你配置的服务；本地模型的外部工具也可能联网。模型凭据与研究导出分开，系统凭据加密能力取决于实际平台及配置。

## 资料在哪，怎样迁移或恢复？

在“设置 → 本地存储”查看实际路径。独立桌面版可迁移到空目录并重启，源库保留为备份。研究 JSON 可跨系统导入，包含报告、对话和来源，不含账号凭据、完整原生状态或外部工作文件；完整备份范围见[使用指南](getting-started.md)。DSH 的路径与会话备份规则另见其文档。

首次使用新版持久材料时，研究目录的 `backups/before-sessionweave-materials-v4/` 会保留升级前的研究库、本地凭据密钥（如有）和 `backup.json`。新会话存档不能由旧 SW 读取；恢复旧版须先退出 QB、另备份当前资料，再完整恢复升级前的数据库和密钥。升级后的新研究不在这份旧备份中，不能靠降低存档版本号或删除材料字段来降级。

## 关掉应用或停止回复会丢失已完成操作吗？

已经保存的内容与成功的图谱操作保留；停止不是回滚。正常退出后重开同一资料位置可继续查看。升级前保留备份；运行旧程序不等于安全降级已写入的数据库。

## 目前验证到哪些系统与模型？

独立应用成品提供 Windows x64、macOS 15 Apple Silicon/Intel、Ubuntu 24.04 x64。Windows 未签名，Mac 尚无 Developer ID 和公证；其他系统与 ARM Linux 未覆盖。模型、OAuth 与智能体的成品验收使用隔离固定响应，不代表所有真实厂商或长期研究均已验证。以[实际 Release](https://github.com/Ethan-decoy/QuestBranch/releases)的附件和 `VERIFICATION.json` 为准。

更多内容见[安装说明](desktop-installation.md)、[第一次研究](getting-started.md)。反馈时提供版本、系统/架构、连接方式、步骤、预期与实际结果；分享前去掉密钥、授权码和私人研究内容，使用 [Issues](https://github.com/Ethan-decoy/QuestBranch/issues)。
